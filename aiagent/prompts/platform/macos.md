# Platform Notes — macOS

- Shell: zsh or bash (see the environment block); POSIX command dialect.
- Case-insensitive filesystem by default.
- Homebrew is the common package manager.
- Sandbox (as reported in the environment block): Seatbelt (sandbox-exec) or Docker. A sandbox denial means wider permission is needed — say so and ask.
- Use the scratchpad directory for temporary files.
